# Install Job Finder (about 5 minutes, no technical skills needed)

You need the **Claude desktop app** (Mac or Windows) and a Claude account.

## 1. Add Job Finder to Claude

1. Open the **Claude** desktop app.
2. Open **Customize** (left sidebar), then **Plugins**.
3. Click **Add**, then **Add marketplace**.
4. Paste this address and confirm: `https://github.com/YoadBarok/job-finder`
   (You don't need a GitHub account.)
5. **Job Finder** now appears in the list. Click **Add**.

**Don't see Plugins?** Use the skill file instead:
1. Download [job-finder-skill.zip](https://github.com/YoadBarok/job-finder/raw/main/dist/job-finder-skill.zip) (don't unzip it).
2. In Claude: **Customize → Skills → + → Upload a skill**, and choose the file.
3. If Claude asks you to turn on **code execution / Create and edit files** (Settings → Capabilities), turn it on.

## 2. Give it a folder

Job Finder keeps your CV, preferences and job applications in **one folder on your computer**.

1. Create a folder, for example **Documents → Job search**.
2. Start a new chat in the Claude desktop app, click **+** (or **Add folder**) and choose that folder.

## 3. Start

Type: **Help me find a job**

Job Finder will:
1. Ask for your **current CV** (attach your PDF or Word file).
2. Ask a few questions: where you live and can work, which roles you want, pay, what to avoid.
3. Rebuild your CV and **ask you to approve it**. This becomes the base for every tailored CV.
4. Search for fresh jobs and show you a short ranked list.

Pick a job, and you'll get a folder with:
- **Your Name CV.pdf** (and a Word version): tailored for that job, only true facts
- **notes.md**: how well you match, gaps, red flags, a short cover note
- **Apply**: double-click to open the application form; **APPLY.md** has the answers to copy

## Everyday use

- "Find me new jobs"
- "Tailor my CV for this job: <paste link or description>"
- "I applied to the Acme job"
- "Show my applications"

## Good to know

- **Always read your CV before sending it.** Job Finder lists anything it isn't sure about and asks you.
- It never applies or messages anyone for you.
- LinkedIn job links often can't be read automatically: paste the job description instead.
- On another computer, connect the same folder (e.g. via iCloud or Dropbox) and just say "help me find a job".
